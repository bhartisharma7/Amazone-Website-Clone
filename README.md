# Amazon Website Clone

A front-end clone of the Amazon shopping website, built using **HTML5 and CSS3**. This project recreates the look and feel of Amazon's homepage, including its navigation bar, search interface, promotional banner, shopping categories, and footer.

## Project Overview

The Amazon Website Clone is a beginner-friendly front-end development project focused on recreating a familiar e-commerce website layout using core web technologies.

It demonstrates the use of HTML for structuring web pages and CSS for styling, layouts, spacing, and interactive hover effects.

## Features

- **Navigation Bar:** Amazon-inspired header with logo, delivery location, search bar, account section, orders, and cart.
- **Search Interface:** Styled search input with category selection and search icon.
- **Hero Section:** Promotional banner with a shopping message.
- **Shopping Categories:** Eight product and category cards featuring images and promotional headings.
- **Footer Section:** Multi-column footer with company information, social links, and customer support sections.
- **Hover Effects:** CSS-based hover effects for navigation elements and search interface.
- **Flexbox Layout:** Flexible page structure for arranging navigation and shopping sections.

## Technologies Used

- HTML5
- CSS3
- Font Awesome 7 (Icons)

## Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/bhartisharma7/Amazone-Website-Clone.git
```

**2. Navigate to the project folder**

```bash
cd Amazone-Website-Clone
```

**3. Run the project**

Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.
